# Ferryman brand assets

Everything here is generated by `gen.py` + `build.py` from a few dozen numbers. To
change the mark, change a number and re-run — there is no binary master to keep in sync
and nothing was traced from a raster.

```
python3 gen.py && python3 build.py
```

## The one decision worth knowing about

**There are two drawings, not three.**

Round 3 used one drawing at every size and let it fail at 16px. It had to: 16×16 is 256
pixels, and a ring, six protruding handles and a letterform cannot all have some. The F
came out a grey smudge.

So below 32px the handles come off and the mark is the ring plus the F. That is *less
detail of the same shape*, not a different shape — which is the test the round-3 brief
set for itself. The crossover was measured, not chosen: see `preview/crossover.png`,
where the full wheel's F is unreadable at 20px, thin at 24px and solid at 32px.

There are no interior chords at any size. The six node-handles are already the endpoints
and the ring is already what joins them; drawing lines between them was the round-1
mistake in a subtler form, and it crowded the F. `preview/tier-c-candidates.png` shows
the three treatments that were tried.

## Which file goes where

| Use | File |
|---|---|
| Windows tray / taskbar | `icons/ferryman.ico` (dark tray: `ferryman-dark.ico`) |
| macOS app bundle | `icons/ferryman.icns` |
| Linux tray / `.desktop` | `png/ferryman-{16,24,32,48,64,128,256}.png` |
| Favicon | `icons/ferryman.ico` or `png/ferryman-32.png` |
| GitHub org / repo avatar | `png/ferryman-512.png` |
| README header, site | `svg/ferryman-logo.svg` |
| Anywhere the mark stands alone | `svg/ferryman-mark.svg` |

`*-dark.*` is the off-white version for dark backgrounds. Both `.ico` files embed art
drawn *for* each size — 16, 20, 24, 32, 48, 64, 128, 256 — rather than one image
resampled eight times.

## Rules

- **Monochrome-safe.** One colour throughout. Some platforms will render a tray glyph as
  a flat single colour whether you like it or not; nothing here breaks when they do.
- **No gradients.** Ever. That treatment is the house style of every AI product of the
  last three years and this audience reads it as marketing.
- **Do not scale the full mark below 32px.** Use the small mark. That is the entire point
  of there being two.
- **The wordmark is outlined**, not `<text>`. It renders identically without Inter
  installed.

## Colour

| | Hex | Use |
|---|---|---|
| Deep navy | `#0D132B` | the mark, on light |
| Off-white | `#FFFFFF` | the mark, on dark |
| Blue grey | `#64748B` | secondary UI text only — never the mark |

## Type

Inter — SemiBold for the wordmark, Regular for the tagline. Already converted to paths
in `svg/ferryman-logo.svg`, so nothing needs installing to render it.

Tagline is **private coordination for AI agents**. Not "agent orchestration platform" —
the product has no platform and no server, and claiming a category it rejects is worse
than saying less.
