# ADR 0009: Routing is advisory until a master-gated, confidence-based redirect exists

An agent cannot reliably judge when another agent is better suited to its task. A smoke test (2026-08-16) showed a SQL-profiled agent solving a Rust borrow-checker puzzle correctly without volunteering that a Rust-specialised agent should take it, because capable models do not self-limit: they just do the work. Routing therefore stays advisory — an agent or reviewer may suggest a better fit in its result or reasoning, and only a human (or, later, the master) acts on it. The reliable routing signal is measured confidence (`EngineStats::confidence()`, derived from accepted/sent-back outcomes) plus the per-agent specialization roster, not self-report. A master-only automatic redirect — keyed on that confidence, logged in the attribution ledger, and gated by the existing master/grants model — is the intended future step and will be designed separately when the fleet needs it.
